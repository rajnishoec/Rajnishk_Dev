## Coverage Lab

- [ai-coverage-lab](ai-coverage-lab/): a CLI and browser dashboard for measured code
  coverage, with optional AI recommendations grounded in uncovered lines.
- [ai-coverage-sample](ai-coverage-sample/): intentionally under-tested Python and
  JavaScript applications for end-to-end verification.

Start with the [Coverage Lab quick start](ai-coverage-lab/README.md#quick-start).
Both projects are contained in this public repository. Their GitHub Actions
workflows run unit tests, real coverage measurements, and browser E2E checks.
